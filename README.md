# WinClip

Move text and files between your iPhone and Windows PC on your local network.

## Download for Windows

Windows 10 (22H2) and Windows 11. No GitHub account or separate .NET installation is needed.

- [WinClip — Intel or AMD](https://github.com/JavTheGod/WinClip/releases/latest/download/WinClip-Intel-or-AMD.zip)
- [WinClip — ARM](https://github.com/JavTheGod/WinClip/releases/latest/download/WinClip-ARM.zip)

1. Quit an older WinClip from its tray menu.
2. Download and extract the ZIP into a permanent folder, then open WinClip.exe.
3. Follow setup and pair your iPhone using the eight-digit code or QR code.

The ZIP contains one executable, a readme and license notices. Pairing and settings are preserved when replacing an older copy. This build includes an automatic updater: install it once, then WinClip checks and installs future updates when it starts. Keep it in a folder your Windows account can write to.

The release assets with the older x64 and arm64 filenames are compatibility copies required by installed automatic updaters. Use the two download links above.
