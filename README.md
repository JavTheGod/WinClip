# WinClip

Clipboard sharing between Windows and iPhone.

## [Download for Windows](https://github.com/JavTheGod/WinClip/releases/download/v0.1.4-discovery.20261116/WinClip-Windows-x64.zip)

Windows 11, x64. No GitHub account or separate .NET installation is needed.

1. Download and extract the ZIP.
2. Open **WinClip.Desktop.exe**.
3. Follow setup, then select your PC in WinClip on iPhone.

The ZIP contains one executable, a readme, and license notices. Quit an older WinClip from its tray menu before replacing it.

The Windows companion is a preview build. The iPhone app is currently distributed separately for testing.
